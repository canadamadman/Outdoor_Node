# Outdoor_Node
A mesh node designed for a all in 1 outdoor node.

Features:
-built in solar mppt
-access to unused GPIO Pins
-GPS header with optional on/off
-2x I2C ports 
-built in battery protection for 18650 cell's

Required:
-pro-micro Nrf52840 
-HT-RA62 Sx1262 ( or any matching pinoutand footprint)
-1-2 18650 battery holder. 
-GPS module
-ipex antenna connection to your choice of antenna

For easy updates to device,on the pro-micro I recommend useing female headers and male pins to attach to main board.

A PCB design that is based off the DIY Pro-Micro, Firmware for Meshtastic. This is a smd version that can be ordered from a pcb manufacturer. I'm open to improvements and modifications.
